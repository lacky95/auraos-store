// Connect

Add this store to your AuraOS

bash
$ aura nexus registry add official \
    https://nexus.aura.lakner.io/index.yaml \
    --kind git-index --priority 10
$ aura nexus search              # then browse it in the Nexus app

Priority 10 sits behind the built-in local registry, so an app you are developing locally still shadows the published one. Don’t have AuraOS yet? Start here.

// Publish

Get your app listed

Runs from source

Push your app to a git repo with app.manifest.json at the root and tag a release. AuraOS installs dependencies on first launch — nothing to build.

sources.git

Needs a build

Build in your own CI and push the result as an OCI artifact. A reusable GitHub Action in the store repo does build → push for you.

aura nexus app publish --kind oci

Is a service or image

Wrap any existing container image with a thin adapter and runtime: "raw". Upstream stays untouched, so upgrades are still docker pull.

sources.oci

Then add one YAML file to apps/ and open a pull request. CI validates the schema, checks that your id matches your manifest, and confirms every declared channel resolves to a tag that exists. Full guide in CONTRIBUTING.md.

Third-party submissions are not open yet — the AuraOS store UI still installs without showing you the permission diff, and we won’t list other people’s code until it does. The reasoning is in POLICY.md.
